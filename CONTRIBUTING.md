# Contributing

Petika is an original MIT-licensed implementation. Submit only original code or material
you have the right to contribute under compatible terms. Do not copy or translate GPL
password-manager implementation code. Keep third-party notices where required.

Discuss architecture changes before introducing a vault format, authentication protocol,
cryptographic construction, or dependency. Follow the [development guide](docs/development.md),
keep documentation aligned with actual capabilities, and run all README checks.

Changes should include focused tests for new behavior. Do not commit passwords, private
keys, personal vaults, tokens, or plaintext import fixtures containing real credentials.
All contributions are provided under the repository's MIT license.
